# Община Кубрат — уебсайт

Модерен, адаптивен статичен сайт за общинска администрация (HTML + CSS + JS, без build стъпка).

## Стартиране
Отворете `index.html` в браузър или пуснете локален сървър:

```bash
python3 -m http.server 8000
```

## Функционалности
- Стъклен (glassmorphism) дизайн, анимиран hero, плавни появявания при скрол
- Светла / тъмна тема (запомня се), смяна на размера на текста (достъпност)
- Е-услуги, новини с филтри, обявления с табове, календар на събития, населени места
- Търсене (бутон, `/` или `Ctrl+K`), форма за контакт с валидация, бюлетин
- Напълно адаптивен — десктоп, таблет, мобилен

## Преди публикуване
Данните в квадратни скоби и примерните контакти (`0000 00 000`, `info@example.bg`, адрес),
както и новините, обявленията и статистиките са **примерно съдържание** — заменете ги с реалните.

## Структура
```
index.html        – страницата
css/styles.css    – стилове и теми
js/main.js        – интерактивност
assets/favicon.svg
```
