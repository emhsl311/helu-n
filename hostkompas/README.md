# ХостКомпас: сайт за сравнение на хостинг (афилиейт)

Модерен, бърз статичен сайт на български: класация на топ 5 хостинга, сравнителна таблица, тест „Кой хостинг е за мен?“, отделни ревюта, ръководства, ЧЗВ, SEO и schema.org. Има тъмна и светла тема и работи добре на телефон.

Не са нужни база данни, WordPress или външни пакети, само **Node.js 18+**.

## Структура

```
hostkompas/
├─ data/
│  ├─ site.mjs     ← име, домейн, имейл, дата на обновяване
│  └─ hosts.mjs    ← ДОСТАВЧИЦИТЕ: партньорски линкове, цени, оценки, текстове
├─ src/            ← шаблони на страниците
├─ public/assets/  ← CSS, JS, иконка, картинка за споделяне (og.png)
├─ build.mjs       ← сглобява сайта в dist/
├─ serve.mjs       ← локален преглед
└─ dist/           ← ГОТОВИЯТ САЙТ (качва се на хостинга)
```

## Как се работи

```bash
cd hostkompas
node build.mjs     # сглобява сайта в dist/
node serve.mjs     # преглед на http://localhost:4321
```

## Чеклист преди пускане

1. **Партньорски линкове.** Регистрирай се в афилиейт програмите и сложи линковете в `data/hosts.mjs` → `affiliateUrl`.
   Всички бутони минават през `/go/<име>/`, така че линкът се сменя на едно място.
   - Hostinger: hostinger.com → Affiliate Program
   - SiteGround: siteground.com → Affiliates
   - Cloudways: cloudways.com → Partners / Affiliate
   - SuperHosting.bg и ICN.bg: провери на сайтовете им дали имат партньорска програма. Ако нямат, остави ги без линк или замени доставчика с друг.
2. **Цени.** Провери актуалните цени (`priceFrom`, `priceNote`) и полетата, в които пише „Провери“ или „Виж плана“. После обнови `updated` и `updatedLabel` в `data/site.mjs`.
3. **Оценки и текстове.** Оценките са редакционно мнение. Ако си тествал хостинг, добави собствения си опит в `review`. Това помага най-много за доверието на читателите и за класирането в Google.
4. **Домейн и имейл.** Попълни `url` и `email` в `data/site.mjs`.
5. Пусни `node build.mjs`.

## Публикуване (безплатно)

**Netlify или Cloudflare Pages (препоръчително)**
- Свържи GitHub хранилището.
- Base directory: `hostkompas`, Build command: `node build.mjs`, Publish directory: `hostkompas/dist`
  (за Netlify това вече е настроено в `netlify.toml`).
- Добави своя домейн в настройките.

**Друг хостинг:** качи съдържанието на `dist/` в `public_html` (например през FTP).

**GitHub Pages в подпапка:** задай `base: "/име-на-repo"` в `data/site.mjs`.

## След пускане

- Добави сайта в **Google Search Console** и подай `sitemap.xml`.
- Пиши още статии (ревюта, сравнения от типа „Hostinger или SiteGround“, ръководства). Повече полезно съдържание носи повече трафик.
- Ако добавиш Google Analytics или друго проследяване, ще ти трябва банер за съгласие с бисквитки (GDPR), а страницата „Поверителност“ трябва да се обнови.
